# STOMP presentation assets

- `stomp-method.pdf`: standalone method diagram supplied by the STOMP authors.
- `stomp-method.png`: 2,000-pixel-wide rendering of that PDF for GitHub display.
- `stomp-poster.pdf`: the authors' MICCAI 2026 poster, preserved as supplied.
- `stomp-poster.png`: 1,200-pixel-wide rendering of the poster for preview.

The PNGs are direct PDF renderings. The scientific diagrams and the original PDFs
have not been redrawn or altered. The README uses the method name from the paper,
**Semantic Token-dropping Masked Pre-training**; the supplied poster uses the
shorter expansion **Semantic TOken Masked Pre-training**.
